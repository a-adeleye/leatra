# Leatra redesign

A responsive, editorial homepage concept for Leatra, built from the supplied visual direction and the live site's public brand content. The six production photographs in `assets/images/leatra-*.png` were generated specifically for this design and form one consistent Lagos-based campaign set.

## Run locally

From this directory, start any static file server. For example:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

The project has no build step or runtime dependencies.
